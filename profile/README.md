### What we run

- **KIRA** — audits a Japanese renovation estimate against **65,520 open cost items**. Returns a fair-price range, the gap, and red flags. It never calls the contractor dishonest; it hands you the numbers and the sources.
- **JHNRD** — home-visit nursing reimbursement rules, each with ranked sources. Never says "you can bill this"; it shows the requirements and what is unconfirmed.
- **JIDEC** — a Bitcoin-anchored public verification ledger. You recompute the hash yourself.
- **YAKUMO** — a directory of independently audited contractors, fail-closed.

### Check any of it in one command

```bash
curl -s https://gate.horizonshield.dev/register
```

Nothing here asks to be trusted. Everything can be recomputed from published bytes.
